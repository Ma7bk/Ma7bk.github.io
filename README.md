# Portfolio de Mahmoud Aziz Ben Khalifa

Site statique prêt pour GitHub Pages : présentation, formation, projets, expériences, compétences et coordonnées.

## Publication

1. Se connecter au compte GitHub Ma7bk.
2. Créer un dépôt public nommé exactement `Ma7bk.github.io`. Si ce dépôt existe déjà, vérifier son contenu avant de le modifier.
3. Extraire l’archive ZIP sur son ordinateur.
4. Importer les fichiers extraits à la racine du dépôt avec « Add file → Upload files ». Ne pas importer le ZIP lui-même ou un dossier contenant les fichiers : `index.html` doit être directement à la racine.
5. Valider avec « Commit changes ».
6. Dans « Settings → Pages », choisir « Deploy from a branch », puis la branche `main` et le dossier `/ (root)`. Cliquer sur « Save ».
7. Attendre la fin de la publication et ouvrir https://ma7bk.github.io/.

L'adresse ci-dessus est la destination prévue, pas une confirmation de mise en ligne. Aucune publication GitHub n'a été effectuée lors de la préparation de cette archive.

Le CV téléchargeable conserve son lien vers le portfolio public actuel tant que la nouvelle adresse n'a pas été vérifiée. Après publication, mettre à jour ce lien dans le CV et remplacer le PDF du dépôt.

Documentation officielle : https://docs.github.com/en/pages/quickstart
